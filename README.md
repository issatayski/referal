# Демо: QR → страница записи → Google Таблица

Демонстрация процесса для заказчика: пациент сканирует QR → открывается мобильная страница
записи → имя и телефон падают в Google Таблицу.

## Файлы
| Файл | Назначение |
|---|---|
| `index.htm` | Страница записи (мобильная вёрстка, логотип, фон, форма Имя + Телефон) |
| `qr.htm` | Экран/памятка с QR-кодом для демонстрации и печати |
| `qr-demo.png` / `qr-demo.svg` | QR с логотипом в центре, ведёт на страницу записи |
| `GOOGLE-TABLE.md` | Инструкция: запись заявок в вашу Google Таблицу |
| `make_qr.py` | Генератор QR с логотипом в центре |
| `iogo.png`, `background.jpg` | Логотип и фон |

## Публикация на GitHub Pages
1. Залить все файлы в корень репозитория `issatayski/referal`.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту страница доступна: `https://issatayski.github.io/referal/`
   (QR ведёт именно на этот адрес).

## Подключение Google Таблицы
Без коннекторов и авторизации. Google Форма работает как невидимый приёмник:
пациент заполняет только нашу страницу, она фоном отправляет данные в форму,
форма пишет строку в связанную таблицу. Пациент форму не видит и никуда
не переходит.

Пошагово (3 минуты) — [GOOGLE-TABLE.md](GOOGLE-TABLE.md). В `index.htm`
заполняются `FORM_ID` и два `entry.*` (Имя, Телефон).

Пока не заполнено, форма работает в демо-режиме: показывает экран
благодарности, но никуда не пишет.

## Реферальные коды
На этапе PHP-системы каждая ссылка получит свой код (`/r/{code}`), и заявки
будут помечаться конкретным реферером. В тестовой странице этого нет —
только Имя и Телефон.
